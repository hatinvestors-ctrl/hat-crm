01 — Overview

What Was Built

HatInvestors CRM now has a full AI-powered deal analysis engine built directly into the lead workflow. No external tools, no copy-pasting numbers — just click a button and get a complete financial analysis in seconds.

The Problem It Solves

Previously, analyzing a deal required switching to a separate agent tool, manually entering numbers, and keeping results in a different system. Now the analysis lives on the lead record, persists across sessions, and opens a rich interactive dashboard with one click.

  • 🤖
    AI-Powered Analysis — Uses Claude AI with Tomer's exact financial model (HML defaults, holding costs, MAO formula, ROI calculations)
  • 💾
    Saved to Lead Record — Analysis results are stored on the lead in Supabase and visible every time you open the lead
  • 📊
    Interactive Dashboard — One click opens the full deal-analyzer.html dashboard pre-filled with the lead's numbers
  • 🔄
    Re-Analyze Anytime — Numbers changed? Run a fresh analysis that replaces the previous one
  • ⚡
    Quick Analysis — Analyze any property without adding it to the CRM first — accessible from the sidebar
  • 🏷
    FLIP + BRRRR Strategies — Toggle between flip and BRRRR analysis before running

What the button does

  • 1

    Pick your strategy

    Toggle between FLIP and BRRRR using the two buttons. The strategy changes how Claude models the deal (holding period, refinance analysis, etc.)

  • 2

    Click "✦ Analyze Deal"

    The button turns to "Analyzing…" with a spinner. The analysis takes 5–20 seconds depending on Claude's response time.

  • 3

    Results appear instantly

    The DealAnalysisPanel renders below the Financial section with verdict, score, metrics, risks, and a full text analysis.

Required Fields

The lead must have Asking Price and ARV filled in. Renovation Cost is optional (defaults to $0). The address is pulled automatically from the lead record.

Activity Timeline

Every time an analysis is run (first time or re-run), a new entry appears in the lead's Activity Timeline: "Deal analysis run — Verdict: BUY / $72,051 profit / 52.3% ROI". This creates a full history of all analyses run on a lead.

Financial Model

The AI uses Tomer's exact financial model: HML defaults (Rob @ 3 Shacks — 90% purchase + 100% reno, 12% rate, 2% points), itemized purchase costs ($1,600 title + $500 lender insurance + $200 doc stamps + $150 intangible tax), holding costs ($208/mo taxes + $100/mo insurance + loan payment), MAO formula (75% × ARV − repairs − costs − min profit), and a 7% selling cost on flip proceeds.
